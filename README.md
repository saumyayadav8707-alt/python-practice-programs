# Python Practice Programs

## Purpose
This repository contains my beginner-level Python practice programs written during my first semester of B.Tech CSE (Data Science and Machine Learning). The goal of this repository is to build a strong foundation in programming logic and problem-solving.

## Tools Used
* **Language:** Python 3
* **Code Editor:** Visual Studio Code

## Implementation
The programs in this repository cover fundamental programming concepts including:
* Variables, user input, and arithmetic operations
* Conditional statements (if-else)
* Loops (for and while loops)
* Basic lists and dictionaries for storing data
* Simple user-defined functions

## Outcome
Regular practice through these exercises has helped me understand Python syntax, write clean code, and prepare for data analysis tasks.
